## Định nghĩa mức coverage

**Complete** = trục đó có source map và giải thích ownership/flow/invariants/test references ở phạm vi tài liệu; không nghĩa runtime/test coverage 100%. **Partial** = có hướng dẫn và nguồn nhưng chưa giải thích mọi biến thể/field. **Not applicable** = trục không thuộc subsystem. **Not verified** = thiếu execution/telemetry để xác nhận. Tất cả live/browser/cloud verification trong task này là Not verified.

Inventory gồm 242 API declarations, 59 mapped SQLAlchemy entities, 40 page files và các service/provider/worker/deploy groups; xem [source map](handbook/source-map.md) để đếm lại, không dùng các số đó làm test coverage. Mỗi module có A–N: purpose/workflow/ownership/map/flow/API/persistence/rules/security/failure/tests/extension/limitations/Q&A.

## Maintenance

Unmapped new router/model/page phải cập nhật source map và module owner; change behavior cần canonical concern doc, không chỉ cập nhật bảng coverage. [Audit](DOCS_AUDIT.md) giữ trạng thái tài liệu cũ; [playbook](handbook/feature-development-playbook.md) chọn impacted tests. Chưa có claim toàn bộ code paths được review hoặc test trong task documentation-only này.
