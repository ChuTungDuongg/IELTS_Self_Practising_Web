Speaking grading is an optional advisory assessment of the whole attempt. FC, LR, GRA and PR receive independent descriptor-based scores. A valid half-band score is committed before feedback starts; feedback cannot change it. One bounded score repair is allowed. Invalid output or technically unassessable audio produces an explicit unavailable/failed state, never a substitute band. The raw four-criterion mean and project half-band result remain separate from official/manual attempt bands.

PR requires current P5 acoustic evidence and cannot score from transcript alone. The lightweight pitch, energy and alignment measurements are limited proxies; they do not establish phoneme accuracy, linguistic stress or examiner agreement. Every criterion rejects unusable audio. Runtime scratch notes, raw files, storage paths and superseded recordings stay outside grading inputs.

`SPEAKING_AI_ENABLED` defaults to false. Provider and model overrides have an independent Speaking prompt/rubric namespace. The adapter reuses configured backend Writing transport credentials and endpoint settings without changing Writing configuration/history. Optional Speaking request/startup timeouts override those transport defaults. Score output is bounded to 128–256 tokens (default 192), feedback to 256–2048 (default 1024). Input over the configured whole-attempt limit fails rather than silently dropping responses. No live provider or speech model is needed for tests.

Grade with AI reuses or starts matching transcript processing and waits for its current P5 evidence. Transcript/quality/normalization/alignment/features/provider versions, committed audio/take fingerprints, rubric/prompt, output contracts and model identity participate in cache identity. Valid score checkpoints survive feedback failure, shutdown and retry. A fenced lease prevents an obsolete worker from committing after recovery. An immediate retry waits for the previous task's cleanup before claiming the same logical run.

JSON snapshots and SSE events use owner or existing assignment provenance authorization. Assignment teachers can observe retained work but cannot start or cancel grading. Events contain bounded status metadata, not transcript/audio/note bodies. SSE replay uses monotonic sequence numbers and disables caching; closing an observer leaves processing running. Only explicit Stop cancels grading. Existing shared transcription remains independent of grading cancellation.
